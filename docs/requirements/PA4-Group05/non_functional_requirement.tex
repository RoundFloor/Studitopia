\hypertarget{sec:current-code-basis}{}
\addcontentsline{toc}{subsection}{Current Code Basis}
\subsection*{Current Code Basis}
\par\medskip

\begin{itemize}
\item Vite hosts the frontend on port \texttt{8999} only during development. In deployment, the NestJS Web package serves the compiled frontend from the backend process.
\item The backend listens on port \texttt{8353} behind a server proxy that ensures TLS protection; database configuration defaults to \texttt{localhost:5432}.
\item Current implemented flows cover authentication/OTP, account read and avatar upload, forum/post/tag read APIs, file read, and SPA asset delivery.
\item Post/comment/vote writes, forum search endpoints, notifications, meeting rooms, privacy settings, moderation, and rate limiting are not implemented in the current source.
\item Time-related NFRs are marked complete based on user-performed testing; the source itself does not contain the measurement artifacts, and scalability targets remain unverified.
\end{itemize}
\par\medskip

Status labels used below:
\par\medskip

\begin{itemize}
\item \textbf{Implemented} - supported by current source code.
\item \textbf{Complete (user-tested)} - a time-related NFR accepted by the user after testing.
\item \textbf{Complete (server proxy)} - satisfied by deployment infrastructure rather than application code.
\item \textbf{Partial} - some supporting code exists, but the full requirement is not satisfied.
\item \textbf{Planned (not implemented)} - documented product intent without current runtime support.
\item \textbf{Target (unverified)} - a design target that has not been measured.
\end{itemize}
