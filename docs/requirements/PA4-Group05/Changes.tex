\hypertarget{sec:version-1-1-28-11-2026}{}
\addcontentsline{toc}{subsubsection}{Version 1.1 - 28/11/2026}
\subsubsection*{Version 1.1 - 28/11/2026}
\par\medskip

\begin{itemize}
\item The PA3 single-file functional requirement set was retained as 241 FRs spanning US-01 to US-40.
\item A \texttt{Status} column was added to every FR row:
\item \texttt{Complete} = source-backed implementation exists.
\item \texttt{Partial} = UI, DTO, SQL, or related support exists but the full flow is not implemented.
\item \texttt{Not implemented} = no source-backed implementation was found.
\item Current status totals are 55 Complete, 20 Partial, and 166 Not implemented.
\item The implementation baseline was made explicit:
\item Implemented: authentication, OTP, account read/avatar, forum browsing, post/tag/file read, Vite development hosting on port \texttt{8999}, and production SPA delivery through the NestJS Web package.
\item Not implemented: friends, meeting rooms, notifications, moderation, privacy settings, full resource management, create post/comment/vote flows, backend search, CAPTCHA, and Google OAuth.
\item The monolithic table set was split into ten functional-group files:
\item \texttt{authentications/requirements.md}
\item \texttt{profiles\_and\_university\_identity/requirements.md}
\item \texttt{browse/requirements.md}
\item \texttt{feeds/requirements.md}
\item \texttt{suggestions\_and\_filters/requirements.md}
\item \texttt{posts/requirements.md}
\item \texttt{learning\_resource\_library/requirements.md}
\item \texttt{friends\_and\_social\_networking/requirements.md}
\item \texttt{meeting\_rooms/requirements.md}
\item \texttt{notifications\_and\_safety/requirements.md}
\item The former \texttt{forums/} group was divided into:
\item Browse: US-11, US-12, US-23.
\item Feed: US-13 except FR-13.3.
\item Posts: US-14 to US-22.
\item Suggestions and Filters: FR-13.3 and US-24.
\end{itemize}
