\hypertarget{sec:2-purpose-and-scope}{}
\addcontentsline{toc}{subsection}{2. Purpose and Scope}
\subsection*{2. Purpose and Scope}
\par\medskip

This document maps the containers described in the Level 2 Container Diagram to the infrastructure that runs them. The current repository contains local-run scripts and service configuration, but no Dockerfile, Docker Compose file, or cloud deployment manifest. The deployment therefore describes a local-machine deployment with separate logical nodes, plus the external cloud services that the backend and browser call.
\par\medskip

The backend and PostgreSQL are configured for the same local host by default, but they are drawn as separate logical nodes because they are separate runtime containers. Vite hosts the frontend on port \texttt{8999} only during development. In deployment, there is no separate frontend server: the NestJS Web package (\texttt{WebModule}/\texttt{WebController}) serves the compiled frontend assets from the backend API process on port \texttt{8353}.
\par\medskip

\subsection*{5. Node Deployment Notes}
\par\medskip

\hypertarget{sec:5-1-node-1-user-device}{}
\addcontentsline{toc}{subsubsection}{5.1 Node 1 - User Device}
\subsubsection*{5.1 Node 1 - User Device}
\par\medskip

\begin{itemize}
\item \textbf{Hardware or cloud service:} A local desktop, laptop, or mobile device running a modern web browser.
\item \textbf{Containers/components running on the node:} The Web Browser container executes the React SPA. Browser-local state includes in-memory Zustand session state and \texttt{sessionStorage} OTP timestamps.
\item \textbf{Communication protocols:} In development, HTTPS to the Vite dev server on port \texttt{8999}; in deployment, HTTP/HTTPS to the backend on port \texttt{8353} for both compiled SPA assets and JSON API responses; HTTPS to Google Fonts.
\end{itemize}
\par\medskip

\hypertarget{sec:5-2-node-2-development-frontend-node}{}
\addcontentsline{toc}{subsubsection}{5.2 Node 2 - Development Frontend Node}
\subsubsection*{5.2 Node 2 - Development Frontend Node}
\par\medskip

\begin{itemize}
\item \textbf{Hardware or cloud service:} Local development machine running the Vite dev server; this node is not used in deployment.
\item \textbf{Containers/components running on the node:} The Vite dev server and the React SPA source modules. Port \texttt{8999} is strict, and HTTPS can be enabled with local certificate files \texttt{certs/server.key} and \texttt{certs/server.crt}.
\item \textbf{Communication protocols:} HTTPS on port \texttt{8999} for development page/assets; Vite hot-module replacement uses a development WebSocket when enabled by the dev server. The backend CORS policy allows \texttt{https://localhost:8999} with credentials for this development origin.
\end{itemize}
\par\medskip

\hypertarget{sec:5-3-node-3-backend-application-node}{}
\addcontentsline{toc}{subsubsection}{5.3 Node 3 - Backend Application Node}
\subsubsection*{5.3 Node 3 - Backend Application Node}
\par\medskip

\begin{itemize}
\item \textbf{Hardware or cloud service:} Local machine running a Node.js process with NestJS 12 on Express 5.
\item \textbf{Containers/components running on the node:} The Backend API Server container, the NestJS Web package as the production frontend host, compiled frontend assets under \texttt{./frontend}, all API controllers/services, and local file storage used for avatars and served files.
\item \textbf{Communication protocols:} \texttt{app.listen(8353)} serves both JSON API traffic and compiled SPA assets; no separate production frontend server is present. The node uses TCP to PostgreSQL, local filesystem I/O for files, and HTTPS to Resend/Discord. No WebSocket endpoint is present in the deployed source.
\end{itemize}
\par\medskip

\hypertarget{sec:5-4-node-4-database-node}{}
\addcontentsline{toc}{subsubsection}{5.4 Node 4 - Database Node}
\subsubsection*{5.4 Node 4 - Database Node}
\par\medskip

\begin{itemize}
\item \textbf{Hardware or cloud service:} Local PostgreSQL service on the same physical development machine as the backend, modeled as a separate logical database node.
\item \textbf{Containers/components running on the node:} The \texttt{studitopia} PostgreSQL database, schema objects, and \texttt{STUDITOPIA.*} stored functions.
\item \textbf{Communication protocols:} PostgreSQL wire protocol over TCP on default port \texttt{5432}, using host \texttt{localhost} and the configured database/user/password.
\end{itemize}
\par\medskip

\hypertarget{sec:5-5-node-5-external-cloud-services}{}
\addcontentsline{toc}{subsubsection}{5.5 Node 5 - External Cloud Services}
\subsubsection*{5.5 Node 5 - External Cloud Services}
\par\medskip

\begin{itemize}
\item \textbf{Hardware or cloud service:} Third-party SaaS endpoints: Resend for email delivery, Discord webhook for fallback delivery, and Google Fonts CDN.
\item \textbf{Containers/components running on the node:} External Resend API, Discord webhook endpoint, and Google Fonts assets.
\item \textbf{Communication protocols:} HTTPS from the backend to Resend/Discord and HTTPS from the browser to Google Fonts.
\end{itemize}
