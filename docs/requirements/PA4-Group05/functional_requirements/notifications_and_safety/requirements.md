### US-38: Receive Notifications

**As a** user, **I want to** receive notifications about relevant activities, **so that** I do not miss important academic interactions.

| FR | Requirement | Category | Status |
| --- | --- | --- | --- |
| **FR-38.1 (Forum Notifications)** | The system shall notify a user about relevant forum activity, including comments, answers, votes, true-response marks, and mentions. | Backend | Not implemented |
| **FR-38.2 (Social Notifications)** | The system shall notify a user about friend requests, messages, group invitations, and help requests. | Backend | Not implemented |
| **FR-38.3 (Room Notifications)** | The system shall notify a user about optional room invitations when the user enables room notifications. | Backend | Not implemented |
| **FR-38.4 (Notification Center)** | The system shall provide an in-app notification center with unread indicators. | UI, Frontend, Backend | Not implemented |
| **FR-38.5 (Notification Preferences)** | The system shall allow users to configure which notification types they receive and whether audio alerts are enabled. | UI, Frontend, Backend | Not implemented |
| **FR-38.6 (Mark Notifications Read)** | The system shall allow users to mark notifications as read. | UI, Frontend, Backend | Not implemented |

### US-39: Control Communication

**As a** user, **I want to** control my communication and privacy settings, **so that** other users cannot interact with me in ways I do not permit.

| FR | Requirement | Category | Status |
| --- | --- | --- | --- |
| **FR-39.1 (Communication Settings)** | The system shall allow a user to control their communication settings. | UI, Frontend, Backend | Not implemented |
| **FR-39.2 (Privacy Settings)** | The system shall allow a user to control their privacy settings. | UI, Frontend, Backend | Not implemented |
| **FR-39.3 (Mute and Block)** | The system shall allow a user to mute or block specific users from messaging, friend requests, or room invitations. | UI, Frontend, Backend | Not implemented |
| **FR-39.4 (Direct Message Restriction)** | The system shall allow a user to restrict direct messages to confirmed friends. | UI, Frontend, Backend | Not implemented |
| **FR-39.5 (Interaction Prevention)** | Communication and privacy settings shall prevent interactions the user does not permit. | Backend | Not implemented |

### US-40: Report Inappropriate Behavior

**As a** user, **I want to** report inappropriate communication or behavior, **so that** the platform can maintain a safe learning environment.

| FR | Requirement | Category | Status |
| --- | --- | --- | --- |
| **FR-40.1 (Report Behavior)** | The system shall allow a user to report inappropriate communication or behavior. | UI, Frontend, Backend | Not implemented |
| **FR-40.2 (Report Surfaces)** | The system shall allow reporting from forum posts, comments, profiles, and messages. | UI, Frontend | Not implemented |
| **FR-40.3 (Report Context)** | The system shall capture contextual information with a report. | Backend | Not implemented |
| **FR-40.4 (Moderation Routing)** | The system shall route reports to the moderation queue. | Backend | Not implemented |
| **FR-40.5 (Safe Environment)** | Reporting shall support maintaining a safe and supportive university learning environment. | Backend | Not implemented |
