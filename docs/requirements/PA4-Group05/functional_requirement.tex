\section*{Functional Requirements}
\par\medskip

\textbf{Version:} \texttt{1.1}
\par\medskip

\textbf{Performed by:} [Nguyen Le Quoc Huy] | \textbf{Edited by:} [Nguyen Le Quoc Huy]
\par\medskip

\begin{quote}
\textit{This file is the index for the split functional requirements. The full requirement tables are grouped by functional area under \texttt{\texttt{functional\_requirements/}}.}
\end{quote}
\par\medskip

\begin{quote}
\textit{Scope note: The requirement files describe product requirements for the Studitopia platform. The Status column reflects current implementation evidence in \texttt{src/frontend}, \texttt{src/backend}, and \texttt{src/database}; it does not remove unimplemented product scope.}
\end{quote}
\par\medskip

\begin{quote}
\textit{Current-code status: \texttt{Complete} means source-backed implementation exists. \texttt{Partial} means UI, DTO, SQL, or related support exists but the full end-to-end requirement is not implemented. \texttt{Not implemented} means no source-backed implementation was found.}
\end{quote}
\par\medskip

\begin{quote}
\textit{Current implementation baseline: authentication, OTP, account read/avatar, forum browsing, post/tag/file read, Vite development hosting on \texttt{8999}, and production SPA delivery through the backend NestJS Web package are implemented. Friends, rooms, notifications, moderation, privacy settings, full resource management, create post/comment/vote flows, backend search, CAPTCHA, and Google OAuth are not implemented.}
\end{quote}
\par\medskip
